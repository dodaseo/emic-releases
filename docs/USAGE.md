# 에믹 사용 설명서

> 2026.10.1.0 기준 설명서입니다. 화면 이름은 앱의 리본·메뉴 이름을 그대로 씁니다.

## 1. 설치
1. [Releases](https://github.com/dodaseo/emic-releases/releases/latest) 에서 `Emic-<버전>-setup.exe` 를 내려받아 실행합니다.
2. Windows SmartScreen 경고가 뜨면 **추가 정보 › 실행** 을 누릅니다. 서명 인증서가 없는 개인 배포라 뜨는 경고입니다.
3. 처음 실행하면 **새 프로젝트** 를 만듭니다. 프로젝트는 고른 폴더의 `project.json` 하나입니다.

## 2. 창 다루기
- 맨 위의 어두운 메뉴줄이 제목 표시줄입니다. 빈 곳을 끌면 창이 옮겨지고, **두 번 누르면 최대화 / 이전 크기** 로 바뀝니다.
  최소화·최대화·닫기 단추는 메뉴줄 오른쪽 끝에 있습니다. 창 가장자리를 끌어 크기를 바꿉니다.
- 왼쪽의 **문서 시스템** · **코드 시스템** 은 머리줄의 분리 단추로 **독립 창** 으로 뗄 수 있습니다(모니터가 둘일 때).
  독립 창에서 문서를 누르면 메인 창에서 열리고, 어느 쪽에서 고쳐도 서로 갱신됩니다. 창을 닫거나 **메인 창으로 되돌리기**,
  또는 상태줄의 **… · 분리됨** 을 누르면 제자리로 돌아옵니다.

## 3. 자료 가져오기
- **파일 › 문서 가져오기** — txt, md, docx, hwp, hwpx. 한글 설치가 필요 없습니다.
  배포용·암호·DRM 문서는 가져올 수 없고, 한글에서 다시 저장한 뒤 가져오라는 안내가 뜹니다.
- **파일 › 음성 전사** — wav, mp3, m4a. 외부 전사 서비스로 보내려면 전송 전에 동의 창이 뜹니다. 동의하지 않으면 아무것도 보내지 않습니다.
  긴 녹음은 480초 단위로 나누어 보내고 이어 붙입니다. 화자 구분과 구간 타임스탬프는 제공자가 주지 않으면 "없음"으로 기록됩니다.
- 자동 전사 결과는 **기계 초안** 입니다. 코딩하기 전에 원음과 대조해 고치세요(4장).
- 실명·연락처를 지우거나 가명으로 바꿀지는 **연구자가 판단** 합니다. 에믹은 가져올 때 개인정보를 검사하거나 처리를 요구하지 않습니다.

## 4. 전사 교정 · 본문 수정
- 오디오 막대 오른쪽의 **전사 교정**(자동 전사 문서) 또는 **본문 수정**(그 밖의 문서)을 켭니다. 코딩은 잠시 멈춥니다.
- 고칠 블록을 누르면 아래에 편집기가 열립니다. **이 블록 듣기** 로 원음과 대조하고, **Ctrl+Enter** 로 저장, **Esc** 로 취소합니다.
  블록 번호를 누르면 그 발화를 재생합니다(오디오가 연결된 문서).
- 코딩한 구간은 고친 글자를 따라 함께 움직입니다. 고친 범위와 겹친 인용에는 '원문 변경' 표시가 붙습니다. 코딩된 구간을 통째로 지우는 수정은 거절합니다.
- 고치기는 **되돌릴 수 있습니다**(Ctrl+Z 또는 저장 뒤 뜨는 되돌리기). 무엇을 고쳤는지 감사추적에 남습니다 —
  가명 처리처럼 지운 글자가 기록에 남으면 안 될 때는 **감사기록에 지운·넣은 글자를 남기지 않음** 을 켭니다(해시와 길이만 남습니다).
- 자동 전사 문서는 **전사 초안 · 교정 n회** 로 표시됩니다. 교정을 마치면 **교정 완료** 를 누릅니다 — 누가·언제가 남고, 디펜스 부록의
  재현 명세에 문서별 전사 단계가 실립니다. 기계 초안은 프로젝트 안에 따로 보존됩니다.

## 5. 코딩
- 본문을 드래그하면 팝오버가 뜹니다. 코드 이름을 적거나 기존 코드를 고릅니다. **숫자키 1~9** 는 최근 코드, **Ctrl+1~9** 는 지정한 코드입니다.
- 겹치는 구간은 겹친 채로 보입니다. 구간을 오른쪽 클릭하면 코드 떼기·재코딩·메모·인용 만들기·연결이 나옵니다.
- **코드 시스템**(왼쪽 아래)에서 계층을 끌어 옮기고, 병합하고, 빈도를 봅니다. **코딩 › 정련 모드** 는 코드 하나의 세그먼트를 한 화면에서 다른 코드로 옮깁니다.
- 코드 없이 구간만 남기려면 **인용** 을 만듭니다. 마지막 코드를 떼도 인용과 메모는 남습니다.
- **되돌리기 / 다시 실행**(Ctrl+Z / Ctrl+Y)은 그 명령이 바꾼 것만 되살립니다. 오디오 연결·수동 앵커는 되돌리기 대상이 아닙니다.

## 6. 왼쪽 패널의 오른쪽 클릭
- **문서 시스템** — 빈 곳: 모든 문서 활성화/비활성화 · 새 문서 그룹 · 모두 접기 · 정렬 › · 가져오기 · 개요.
  그룹: 그룹 문서 활성화 · 이름 바꾸기 · 삭제(문서는 '그룹 없음'으로 남음). 문서: 활성화 · 이 문서의 코드만 활성화 · 열기 · 이름 바꾸기(F2) ·
  그룹으로 옮기기 › · 텍스트로 내보내기 · 문서 메모 · AI 보조 › · 문서 집합에 추가 › · 오디오 연결.
- **코드 시스템** — 코드: 활성화(하위 코드 포함) · 이 코드가 있는 문서 활성화 · 하위 코드 추가 · 이름·색상 편집(F2) · **색 견본** ·
  코드 메모 · AI 보조 › · 즐겨찾기 · 단축키 지정 · 코드 집합에 추가 › · 하위 코드 정렬 › · 세그먼트 보기 · 정련 모드 · 키워드 자동 코딩 · 개요(코드맵·매트릭스·관계).
- 메뉴는 키보드로도 다룹니다 — ↑↓ 이동 · → 하위 메뉴 · ← 닫기 · Enter 실행 · Esc 닫기.

## 7. 오디오 동기화
- 오디오 막대의 **오디오 연결** 로 녹음 파일을 연결합니다. 발화 번호를 누르면 그 구간을 재생하고, **Sync** 를 켜면 재생 위치가 본문을 따라갑니다.
- 타임스탬프가 없는 전사본은 재생 중 **Ctrl+Shift+T** 로 현재 시각을 선택 시작점에 수동 앵커로 찍습니다.

## 8. 분석
**분석** 탭의 **분석 도구** 에 여러 탭이 있습니다 — 문서·변수 · 복합 검색 · 코드 메트릭스 · 코드 관계 · 요약 그리드 · 코드맵 · 단어·문맥 · 보고서.
- 범위 카드에서 문서·코드·그룹·변수·집합으로 범위를 정합니다. **활성 선택 저장** 으로 범위를 기억합니다.
- **코드맵** 은 자료와 연결되어 있습니다. 노드를 끌어 다른 노드에 놓으면 관계(축코딩)를 만들고, 더블클릭하면 그 코드의 세그먼트로 갑니다.
  연구자 관계(실선)와 공출현(점선, 두께 = 횟수)을 구분해 그립니다. PNG 로 내보낼 수 있습니다.
- **복합 검색** 의 정의는 **저장 질의** 로 두고, 논문에 쓴 결과는 **스냅샷** 으로 고정합니다. 나중에 비교하면 달라진 것을 말해 줍니다.
- **단어·문맥** 은 형태소 분석(Kiwi)입니다. **Kiwi 설정** 에서 품사·사용자 사전·분석 단위를 고치고, 전후 비교를 본 뒤 **확정** 합니다. 확정 해시가 재현 명세에 남습니다.

## 9. AI 보조
**AI 보조** 탭. 연결 설정은 **설정 › AI 연결** 에 있습니다(AI 보조 화면의 **연결 설정** 단추로도 갑니다).
- **1차 제공자 · 대체 제공자** — 로컬 AI(Ollama·LM Studio 등 OpenAI 호환 서버, 이 PC 의 주소만) · Claude/Codex/Antigravity CLI(내 구독) ·
  Anthropic/OpenAI/Gemini API 키. 1차가 실패하면 대체 제공자로 다시 시도하고, 그 사실을 알립니다.
- **모델 조회 / 연결 확인** — 분석 자료는 보내지 않습니다(API 는 키만 그 제공자에게 갑니다). 목록에 없는 모델은 **직접 입력…**.
- **CLI 설치·로그인** — 각 제공사의 공식 설치 명령을 보이는 창에서 실행합니다. 제공사·받는 곳·약관을 보여 주고 동의해야 시작합니다.
  **추론 강도** 는 CLI 에서만 고르며, 감사·제안 기록에 함께 남습니다.
- 외부 제공자는 실행할 때마다 보낼 범위와 목적지를 보여 주고 동의를 받습니다. 동의는 전송 전에 감사추적에 남습니다.
- **문서 단위 제안** — 코딩 제안 · 문서 요약 · 자료에 질문. **코드 단위 제안** — 병합 후보 · 메모 초안 · 축코딩 후보 · 상시비교(반증 후보).
- 제안 카드에서 **수락 · 고쳐서 수락 · 거절(사유)** 중 하나를 고릅니다. 수락한 메모·관계에는 모델·제안 번호가 함께 남습니다(배지에 마우스를 올리면 보입니다).
- **승인율 · 거절 사유** 탭에 집계가 남고, 디펜스 부록에 실립니다.

## 10. 메모·검색·감사추적
- **메모·검색** 탭 — 성찰·반증·비교·이론·방법·검토·전략 유형의 메모를 코드·세그먼트·문서에 붙입니다. 전역 검색은 본문·코드·메모를 한 번에 찾습니다.
- **감사추적** — 모든 변경이 일시·이벤트·대상·출처(사람·AI·검색)·상세와 함께 남습니다. 지울 수 없습니다.

## 11. 보고서
**보고서** 탭.
- **코드북 버전** — 지금 코드 체계를 이름 붙여 고정합니다. 두 시점을 비교(diff)하고, 포화 곡선을 봅니다.
- **참여자 확인** — 회차를 만들고 발췌를 고른 뒤 **md·docx** 로 내보냅니다. 발췌·해석에 실명·연락처처럼 보이는 것이 있으면 알려 주지만
  막지는 않습니다 — 보낼지는 연구자가 정합니다(메모를 남길 수 있습니다). 돌아온 응답(동의·부분 동의·불일치·불명)을 기록하고
  메모·재코딩·해석 수정으로 소급 반영합니다.
- **디펜스 부록** — 개요 · 코드북 이력 · AI 사용·승인율 · 성찰 기록 · 재현 명세(문서별 전사 단계 포함) · 감사 요약 · member-checking 등을
  Markdown·JSON 으로 내보냅니다. 본문은 싣지 않고, 메모 본문은 연구자가 켤 때만 싣습니다.

## 12. 업데이트
- 앱이 시작할 때 새 판이 있으면 알려 줍니다. **도움말 › 업데이트 확인** 에서 내려받아 SHA-256 을 검증한 뒤, 앱을 닫고 설치 폴더를 교체해 다시 엽니다.
- 교체에 실패하면 이전 판으로 되돌리고 다음 실행 때 이유를 알려 줍니다. 프로젝트 파일은 설치 폴더 밖에 있어 영향받지 않습니다.
- **도움말 › 에믹 정보** 에 지금 판과 제3자 구성요소(라이선스)가 있습니다.

## 13. 설정
**설정** — 서명(감사추적에 남는 이름), 테마(4종), 기본 하이라이트 색, 백업, **AI 연결**, 음성 전사. 키는 이 PC 의 `%LOCALAPPDATA%` 에만 저장됩니다.
