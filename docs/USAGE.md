# 에믹 사용 설명서

> 첫 공개 릴리스 전의 설명서입니다. 화면 이름은 현재 개발 중인 버전의 리본·메뉴 이름을 그대로 씁니다.

## 1. 설치
1. [Releases](https://github.com/dodaseo/emic-releases/releases/latest) 에서 `Emic-<버전>-setup.exe` 를 내려받아 실행합니다.
   (아직 공개 릴리스가 없으면 이 단계는 비어 있습니다.)
2. Windows SmartScreen 경고가 뜨면 **추가 정보 › 실행** 을 누릅니다. 서명 인증서가 없는 개인 배포라 뜨는 경고입니다.
3. 처음 실행하면 **새 프로젝트** 를 만듭니다. 프로젝트는 고른 폴더의 `project.json` 하나입니다.

## 2. 자료 가져오기
- **파일 › 문서 가져오기** — txt, md, docx, hwp, hwpx. 한글 설치가 필요 없습니다.
  배포용·암호·DRM 문서는 가져올 수 없고, 한글에서 다시 저장한 뒤 가져오라는 안내가 뜹니다.
- **파일 › 음성 전사** — wav, mp3, m4a. 외부 전사 서비스로 보내려면 전송 전에 동의 창이 뜹니다. 동의하지 않으면 아무것도 보내지 않습니다.
  긴 녹음은 480초 단위로 나누어 보내고 이어 붙입니다. 화자 구분과 구간 타임스탬프는 제공자가 주지 않으면 "없음"으로 기록됩니다.
- **실명·연락처 검토(PII)** — 가져온 직후 검토 창이 뜹니다. 닫는 길은 셋뿐입니다: **치환**(본문 글자를 바꿈, 되돌릴 수 없음) ·
  **문서 가명화**(표시명을 바꾸고 원 파일명·경로는 감사추적에만 남김) · **의도적 무시**(사유 필수).
  연결된 오디오 파일 이름에 실명이 있으면 앱이 바꾸지 않고 알리기만 합니다 — 탐색기에서 이름을 바꾼 뒤 **이름을 바꾼 파일로 다시 연결** 을 누릅니다.

## 3. 코딩
- 본문을 드래그하면 팝오버가 뜹니다. 코드 이름을 적거나 기존 코드를 고릅니다. **숫자키 1~9** 는 최근 코드, **Ctrl+1~9** 는 지정한 코드입니다.
- 겹치는 구간은 겹친 채로 보입니다. 구간을 오른쪽 클릭하면 코드 떼기·재코딩·메모·인용 만들기·연결이 나옵니다.
- **코드 시스템**(왼쪽 아래)에서 계층을 끌어 옮기고, 병합하고, 빈도를 봅니다. **코딩 › 정련 모드** 는 코드 하나의 세그먼트를 한 화면에서 다른 코드로 옮깁니다.
- 코드 없이 구간만 남기려면 **인용** 을 만듭니다. 마지막 코드를 떼도 인용과 메모는 남습니다.
- **되돌리기 / 다시 실행**(Ctrl+Z / Ctrl+Y)은 그 명령이 바꾼 것만 되살립니다. 치환·가명화·오디오 연결·PII 판정은 되돌리기 대상이 아닙니다.

## 4. 오디오 동기화
- 문서 도구줄의 **오디오 연결** 로 녹음 파일을 연결합니다. 발화 번호를 누르면 그 구간을 재생하고, **Sync** 를 켜면 재생 위치가 본문을 따라갑니다.
- 타임스탬프가 없는 전사본은 재생 중 **Ctrl+Shift+T** 로 현재 시각을 선택 시작점에 수동 앵커로 찍습니다.

## 5. 분석
**분석** 탭의 **분석 도구** 에 여덟 탭이 있습니다 — 문서·변수 · 복합 검색 · 코드 메트릭스 · 코드 관계 · 요약 그리드 · 코드맵 · 단어·문맥 · 보고서.
- 범위 카드에서 문서·코드·그룹·변수·집합으로 범위를 정합니다. **활성 선택 저장** 으로 범위를 기억합니다.
- **코드맵** 은 자료와 연결되어 있습니다. 노드를 끌어 다른 노드에 놓으면 관계(축코딩)를 만들고, 더블클릭하면 그 코드의 세그먼트로 갑니다.
  연구자 관계(실선)와 공출현(점선, 두께 = 횟수)을 구분해 그립니다. PNG 로 내보낼 수 있습니다.
- **복합 검색** 의 정의는 **저장 질의** 로 두고, 논문에 쓴 결과는 **스냅샷** 으로 고정합니다. 나중에 비교하면 달라진 것을 말해 줍니다.
- **단어·문맥** 은 형태소 분석(Kiwi)입니다. **Kiwi 설정** 에서 품사·사용자 사전·분석 단위를 고치고, 전후 비교를 본 뒤 **확정** 합니다. 확정 해시가 재현 명세에 남습니다.

## 6. AI 보조
**AI 보조** 탭. 로컬 AI(Ollama·LM Studio 등 OpenAI 호환 서버)가 기본이고, 외부 제공자는 설정에서 키를 넣고 전송마다 동의합니다.
- **문서 단위 제안** — 코딩 제안 · 문서 요약 · 자료에 질문.
- **코드 단위 제안** — 병합 후보 · 메모 초안 · 축코딩 후보 · 상시비교(반증 후보). 병합 후보는 AI 없이도 이 PC 에서 계산합니다.
- 제안 카드에서 **수락 · 고쳐서 수락 · 거절(사유)** 중 하나를 고릅니다. 근거가 바뀐 제안은 `stale` 로 표시되고 수락할 수 없습니다.
- **승인율 · 거절 사유** 탭에 집계가 남고, 디펜스 부록에 실립니다.

## 7. 메모·검색·감사추적
- **메모·검색** 탭 — 성찰·반증·비교·이론·방법·검토·전략 유형의 메모를 코드·세그먼트·문서에 붙입니다. 전역 검색은 본문·코드·메모를 한 번에 찾습니다.
- **감사추적** — 모든 변경이 일시·이벤트·대상·출처(사람·AI·검색)·상세와 함께 남습니다. 지울 수 없습니다.

## 8. 보고서
**보고서** 탭.
- **코드북 버전** — 지금 코드 체계를 이름 붙여 고정합니다. 두 시점을 비교(diff)하고, 포화 곡선을 봅니다.
- **참여자 확인** — 회차를 만들고 발췌를 고른 뒤 **md·docx** 로 내보냅니다. 발췌에 실명 후보가 남아 있으면 내보내기가 막힙니다.
  돌아온 응답(동의·부분 동의·불일치·불명)을 기록하고 메모·재코딩·해석 수정으로 소급 반영합니다.
- **디펜스 부록** — 개요 · 코드북 이력 · AI 사용·승인율 · 성찰 기록 · 재현 명세 · 감사 요약 · PII 처리 기록 · member-checking 의 8절을
  Markdown·JSON 으로 내보냅니다. 본문과 실명 값은 싣지 않고, 메모 본문은 연구자가 켤 때만 싣습니다.

## 9. 설정
**설정** — 서명(감사추적에 남는 이름), 테마(4종), 백업 폴더, AI·전사 연결. 키는 이 PC 의 `%LOCALAPPDATA%` 에만 저장됩니다.
