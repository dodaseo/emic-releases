# 자주 묻는 질문

## 어디서 내려받나요? 업데이트는요?
[최신 릴리스](https://github.com/dodaseo/emic-releases/releases/latest) 의 `Emic-<버전>-setup.exe` 입니다. 소개 페이지
[emic.dodaseo.cc](https://emic.dodaseo.cc) 의 내려받기 단추도 같은 파일을 가리킵니다. 설치한 뒤에는 앱이 시작할 때 새 판을 알려 주고,
**도움말 › 업데이트 확인** 에서 내려받아 체크섬을 검증한 뒤 앱을 닫고 교체해 다시 엽니다. 프로젝트 파일은 건드리지 않습니다.

## 자료는 어디에 저장되나요?
프로젝트는 고른 폴더의 `project.json` 하나입니다. 저장할 때마다 같은 폴더에 세대 백업(`.bak.1~3`)과 날짜 백업을 남깁니다.
에믹이 운영하는 서버는 없습니다.

## OneDrive 같은 동기화 폴더에 프로젝트를 둬도 되나요?
됩니다 — 기관이 허용한 저장소인지는 연구자가 확인해 주세요. 에믹은 저장할 때 임시 파일에 쓴 뒤 한 번에 바꿔치기하므로
동기화 중에 파일이 반쯤 쓰이는 일은 없습니다. 다만 **같은 프로젝트를 두 PC 에서 동시에 열지 마세요.** 이번 판은 다른 곳에서 열려 있는지를
알아채지 못해, 나중에 저장한 쪽이 앞의 작업을 덮을 수 있습니다(다음 판에서 막을 예정입니다). 백업 세대도 함께 동기화된다는 점도 기억해 주세요.

## 클라우드나 계정이 필요한가요?
아니요. 로그인이 없습니다. PC 밖으로 나가는 요청은 모두 선택이거나 내용이 없는 확인입니다 — 동의한 음성 전사 요청, 동의한 AI 요청,
모델 목록 조회(키만 그 제공자에게), CLI 설치(제공사에서 내려받기, 동의 후), 업데이트 확인(GitHub 에 최신 판을 물음).
자세한 것은 [개인정보 처리방침](PRIVACY.md).

## 자동 전사 결과를 고칠 수 있나요?
네. 자동 전사는 기계 초안이고, 코딩하기 전에 원음과 대조해 고치는 것이 맞습니다. 오디오 막대 오른쪽의 **전사 교정** 을 켜고 블록을 누르면
편집기가 열립니다 — **이 블록 듣기** 로 대조하며 고치고 Ctrl+Enter 로 저장합니다. 코딩한 위치는 함께 움직이고, 고치기는 되돌릴 수 있으며,
기계 초안은 따로 보존됩니다. 다 고쳤으면 **교정 완료** 를 누르세요. 일반 문서도 같은 방식으로 **본문 수정** 을 할 수 있습니다.

## 실명·연락처는 에믹이 지워 주나요?
아니요. 개인정보를 지우거나 가명으로 바꿀지는 연구자의 윤리적 판단입니다. 에믹은 가져올 때 개인정보를 검사하거나 처리를 요구하지 않습니다.
본문을 직접 고칠 때 지운 글자가 기록에 남으면 안 된다면, 편집기의 **감사기록에 지운·넣은 글자를 남기지 않음** 을 켜세요.
고치기 전 본문은 백업 세대에 남아 있을 수 있으니 반출할 때는 프로젝트 파일만 보내세요.

## AI 없이도 쓸 수 있나요?
네. 코딩·분석·보고서는 AI 없이 동작합니다. 병합 후보는 AI 없이도 이 PC 에서 계산합니다.
AI 를 쓰려면 **설정 › AI 연결** 에서 로컬 모델 서버(Ollama·LM Studio 등)를 연결하거나, 내 구독 CLI(Claude·Codex·Antigravity)나 API 키를 씁니다.

## ATLAS.ti · MAXQDA · NVivo 프로젝트를 가져올 수 있나요?
아직 안 됩니다. 가져오는 형식은 txt·md·docx·hwp·hwpx 뿐입니다.
세 도구가 모두 지원하는 교환 규격 **REFI-QDA(`*.qdc` 코드북 · `*.qdpx` 프로젝트)** 가져오기·내보내기를 예정하고 있습니다.

## hwp 파일을 가져오려면 한글이 설치되어 있어야 하나요?
아니요. hwp(5.0)·hwpx 를 순수 파이썬으로 읽습니다. 배포용·암호·DRM 문서는 읽을 수 없고, 한글에서 다시 저장한 뒤 가져오라는 안내가 뜹니다.
표 셀과 각주는 품은 문단 뒤에 한 줄씩 들어가고, 머리말·꼬리말·숨은 설명은 본문에서 빠집니다.

## 모니터 두 대로 쓸 수 있나요?
네. 왼쪽의 문서 시스템·코드 시스템을 머리줄의 분리 단추로 독립 창으로 떼어 다른 모니터에 둘 수 있습니다. 두 창은 서로 갱신됩니다.

## 실행이 안 되거나 화면이 비어 있어요
- Windows 10 이면 Microsoft Edge WebView2 런타임이 필요합니다. Edge 가 설치되어 있으면 보통 함께 있습니다.
- 처음 실행할 때 SmartScreen 경고는 **추가 정보 › 실행** 으로 지나갑니다.
- 그래도 안 되면 [Issues](https://github.com/dodaseo/emic-releases/issues/new) 에 Windows 버전과 함께 알려 주세요.
  실제 면담 자료는 첨부하지 마세요.

## 제안이나 결함은 어디에 알리나요?
[GitHub Issues](https://github.com/dodaseo/emic-releases/issues/new). 재현 절차와 화면 캡처가 있으면 빠릅니다 — 캡처에 참여자 실명이 들어가지 않게 해 주세요.
