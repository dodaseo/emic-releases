# 에믹 개인정보 처리방침

> 2026-10-30 작성. 첫 공개 릴리스에 맞춰 시행합니다.

에믹은 이 PC 에서 도는 프로그램이고, 에믹이 운영하는 서버가 없습니다. 로그인·계정·사용 기록 수집이 없습니다.
이 문서는 그래도 PC 밖으로 나갈 수 있는 두 가지 전송과, 소개 페이지의 외부 요청을 설명합니다.

## 에믹이 수집하는 것
없습니다. 사용 통계·오류 보고·식별자를 보내지 않습니다.

## PC 밖으로 나갈 수 있는 것 (둘 다 선택이며, 동의한 뒤에만)

### 1. 음성 전사
외부 전사 제공자를 고르고 **전송 전 동의 창에서 동의한 경우에만** 녹음 파일(480초 단위로 나눈 조각)이 그 제공자에게 갑니다.
동의하지 않으면 한 바이트도 보내지 않습니다. 동의 기록은 전송보다 먼저 감사추적에 남습니다. 제공자가 받은 음성을 어떻게 다루는지는
그 제공자의 약관을 따릅니다. 로컬 전사 모델을 쓰면 아무것도 나가지 않습니다.

### 2. AI 제안
외부 AI 제공자를 고르고 **요청마다 동의한 경우에만** 보낼 범위의 텍스트(문서 또는 세그먼트 발췌, 번호를 붙인 자료)가 그 제공자에게 갑니다.
보내기 전에 무엇을 몇 글자 보내는지 미리보기로 보여 주고, 미리보기와 실제 전송 내용이 다르면 보내지 않습니다.
로컬 AI(Ollama·LM Studio 등)를 쓰면 아무것도 나가지 않습니다. 모델·프롬프트 버전은 재현 명세에 남습니다.

## 실명·연락처(PII)
가져온 직후 실명·전화번호·이메일 후보를 찾아 검토를 요구합니다. 치환·가명화·의도적 무시 가운데 하나로 연구자가 판정하며,
가명화한 원 파일명·경로는 감사추적 이벤트에만 남습니다. 참여자 확인 발췌본과 디펜스 부록은 실명 후보가 남아 있으면 내보내기를 막거나 경고합니다.
이 검사는 보조 수단입니다 — 익명화의 책임은 연구자에게 있습니다.

## API 키
외부 제공자의 키는 이 PC 의 `%LOCALAPPDATA%` 아래 설정 파일에만 저장됩니다. 프로젝트 파일에는 들어가지 않습니다.

## 소개 페이지 (emic.dodaseo.cc)
페이지를 열면 브라우저가 GitHub 의 릴리스 API(`api.github.com`)에 최신 버전을 물어 내려받기 링크를 채웁니다.
이 요청은 GitHub 의 개인정보 처리방침을 따릅니다. 페이지 자체는 쿠키·분석 스크립트를 쓰지 않습니다.
글꼴은 jsDelivr·Google Fonts 에서 받습니다.
