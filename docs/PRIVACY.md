# 에믹 개인정보 처리방침

> 2026-10-30 개정(2026.10.1.0). 처음 시행 2026-10-30(2026.10.0.0).

에믹은 이 PC 에서 도는 프로그램이고, 에믹이 운영하는 서버가 없습니다. 로그인·계정·사용 기록 수집이 없습니다.
이 문서는 그래도 PC 밖으로 나갈 수 있는 요청과, 소개 페이지의 외부 요청을 설명합니다.

## 에믹이 수집하는 것
없습니다. 사용 통계·오류 보고·식별자를 보내지 않습니다.

## 연구 자료가 PC 밖으로 나갈 수 있는 경우 (둘 다 선택이며, 동의한 뒤에만)

### 1. 음성 전사
외부 전사 제공자를 고르고 **전송 전 동의 창에서 동의한 경우에만** 녹음 파일(480초 단위로 나눈 조각)이 그 제공자에게 갑니다.
동의하지 않으면 한 바이트도 보내지 않습니다. 동의 기록은 전송보다 먼저 감사추적에 남습니다. 제공자가 받은 음성을 어떻게 다루는지는
그 제공자의 약관을 따릅니다. 로컬 전사 모델을 쓰면 아무것도 나가지 않습니다.

### 2. AI 제안
외부 AI 제공자(API 또는 구독 CLI)를 고르고 **요청마다 동의한 경우에만** 보낼 범위의 텍스트(문서 또는 세그먼트 발췌, 번호를 붙인 자료)가
그 제공자에게 갑니다. 보내기 전에 무엇을 몇 글자 어디로 보내는지 미리보기로 보여 주고, 미리보기와 실제 전송 내용이 다르면 보내지 않습니다.
1차 제공자가 실패해 대체 제공자로 넘어갈 수 있다는 점도 동의 범위에 들어갑니다. 로컬 AI(Ollama·LM Studio 등, 이 PC 의 주소만)를 쓰면
아무것도 나가지 않습니다. 모델·프롬프트 버전·추론 강도는 재현 명세에 남습니다.

## 연구 자료 없이 나가는 요청

### 3. 모델 목록 조회 · 연결 확인
**설정 › AI 연결** 에서 [모델 조회]를 누르면 API 제공자에게 **키만** 보내 모델 목록을 받습니다. 분석 자료는 보내지 않습니다.
로컬 서버는 이 PC 안의 주소에만 묻습니다.

### 4. CLI 설치 · 로그인 · 업데이트
구독 CLI(Claude Code · Codex · Antigravity)를 설치하면, 보이는 콘솔 창에서 **각 제공사의 공식 설치 명령** 이 그 제공사 서버에서 프로그램을 내려받습니다.
설치 전에 제공사·받는 곳·약관을 보여 주고 동의해야 시작합니다. 로그인은 제공사의 계정 화면(브라우저)에서 이루어지고, 에믹은 그 자격 증명을 보지 않습니다.

### 5. 업데이트 확인
앱이 시작할 때와 **도움말 › 업데이트 확인** 을 누를 때 GitHub(`api.github.com`)에 최신 판을 묻고, 업데이트를 고르면 GitHub 에서 설치 파일을 내려받습니다.
연구 자료나 식별자는 보내지 않습니다. 이 요청은 GitHub 의 개인정보 처리방침을 따릅니다.

## 실명·연락처
에믹은 가져올 때 개인정보를 검사하거나 처리를 요구하지 않습니다. 익명화·가명화를 할지, 어떻게 할지는 **연구자의 윤리적 판단과 책임** 입니다.
본문을 고칠 때 지운 글자가 감사기록에 남으면 안 되면, 편집기에서 글자 대신 해시와 길이만 남기도록 고를 수 있습니다.
고치기 전 본문은 세대·날짜 백업에 남을 수 있습니다 — 반출할 때는 프로젝트 파일만 보내세요.

## API 키
외부 제공자의 키는 이 PC 의 `%LOCALAPPDATA%` 아래 설정 파일에만 저장됩니다. 프로젝트 파일에는 들어가지 않습니다.

## 소개 페이지 (emic.dodaseo.cc)
페이지를 열면 브라우저가 GitHub 의 릴리스 API(`api.github.com`)에 최신 버전을 물어 내려받기 링크를 채웁니다.
이 요청은 GitHub 의 개인정보 처리방침을 따릅니다. 페이지 자체는 쿠키·분석 스크립트를 쓰지 않습니다.
글꼴은 jsDelivr·Google Fonts 에서 받습니다.
