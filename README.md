# 에믹 (Emic) — 질적분석 스튜디오

한국어로 질적 연구를 하는 사람을 위한 분석 도구입니다. 면담 전사·가져오기 → 코딩 → 코드맵·분석 → 성찰메모 →
참여자 확인(member-checking) → 디펜스 부록까지 한 프로그램에서 합니다. **AI 는 근거를 들어 제안하고, 판정은 연구자가
합니다.** 프로젝트는 이 PC 의 파일 하나이고, 외부로 나가는 전송(음성 전사·AI)은 동의 없이는 일어나지 않습니다.

소개 페이지: **https://emic.dodaseo.cc**

## 내려받기

**[최신 릴리스](https://github.com/dodaseo/emic-releases/releases/latest)** 에서 `Emic-<버전>-setup.exe` 를 내려받아 실행합니다.
관리자 권한이 필요 없습니다(`%LOCALAPPDATA%\Programs\Emic` 에 설치). 처음 실행할 때 SmartScreen 경고가 뜨면 **추가 정보 › 실행**.
다음 판부터는 앱이 새 판을 알려 주고 **도움말 › 업데이트 확인** 에서 내려받아 검증한 뒤 스스로 교체합니다.
각 파일의 SHA-256 은 같은 이름의 `.sha256` 자산과 릴리스 노트에 있습니다.

## 필요한 것

- Windows 10/11 (64비트)
- Microsoft Edge WebView2 런타임 — Windows 11 에는 들어 있습니다
- 음성 전사·AI 는 선택 사항입니다. 로컬 모델을 쓰거나, 동의한 뒤 외부 제공자를 씁니다
- hwp·hwpx 가져오기에 한글 설치가 필요하지 않습니다
